# Daniflames Graphics Client Delivery Portal

## Open in Visual Studio Code
1. Extract this ZIP file.
2. Open VS Code.
3. Select **File > Open Folder**.
4. Select the extracted `Daniflames-Graphics-Portal` folder.
5. Open `index.html`.

## Run the website
Recommended: install the VS Code extension **Live Server** by Ritwick Dey:
1. Open Extensions with `Ctrl+Shift+X`.
2. Search for `Live Server`.
3. Install it.
4. Right-click `index.html` and select **Open with Live Server**.
5. Your browser opens the local site. Save edits in VS Code and Live Server refreshes the browser.

Alternative: double-click `index.html` to open it in a browser.

## Files
- `index.html`: page structure and content.
- `style.css`: visual design, colours, layout and responsive rules.
- `app.js`: interactions and demo project form.
- `assets/`: place logos, images and other local assets here.

## Important
This is a front-end prototype. It does NOT upload artwork to online storage, save projects after closing the browser, create real private links, or securely deliver original files. Do not use it for confidential client delivery yet. We will add a database, protected storage, watermarked preview generation and secure expiring/revocable links in later stages.

No Node.js, npm, framework, or `package.json` is required for this first static prototype.
